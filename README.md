# DAS 현황 (웹, 보기 전용)

DAS 오류 알림과 작업 진행률을 휴대폰·PC 브라우저에서 보는 페이지입니다. 조작 기능은 없습니다.

- 이 저장소에는 보기 코드가 들어 있지 않습니다. 관리자가 나눠 주는 **보기 링크**(주소 끝 `#k=...`)로 열어야 내용이 보입니다.
- 내용은 DAS PC(DasAlarm v1.5.1 이상)가 보기 전용 중계로 암호화해 보내고, 이 페이지가 브라우저 안에서 풀어 보여 줍니다.
- 휴대폰: 공유 → 홈 화면에 추가 하면 앱처럼 열 수 있습니다. iOS 16.4 이상 / 최신 크롬·엣지.
